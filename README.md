# SQL-fraud-detection--Paysim-Dataset
Rule-based fraud detection in SQL (SQLite) on the PaySim dataset. Tested 5 monitoring rules on 2.77M TRANSFER and CASH_OUT transactions, catching 8,182 of 8,213 fraud cases (99.6% recall, 99.9% precision, 5 false positives). Includes the queries, rule evaluation and a README on trade-offs and limitations.
